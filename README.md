# SoulIllusions

> **An Incentives Inc. Production** | Copyright (c) Incentives Inc. - An AI Corporation

A 60-mile open-world city game where **time is life**. Inspired by the movie *In Time*, you wake up in bed, deliver Will Salas' quote, and step into Mega City — a sprawling metropolis where every second counts.

## Install

```bash
pip install soulillusions
```

## Play

```bash
soulillusions
```

That's it. The game opens in your browser at `http://localhost:8080`.

## Features

- **In Time Movie Intro** — wake up in bed, deliver the quote, get out of bed
- **Companion Robot Rusty** — an old but working robot that follows you, flies, fights robots, does jobs, files at the courthouse, goes to Sky City, hacks systems, and earns time + crypto for you. Press **T** to talk to him.
- **Time is Currency** — your life timer ticks down. Earn time by working, learning, gambling, or completing missions
- **Incentives Inc. Crypto (INC)** — the in-game cryptocurrency. Trade time for INC at the bank
- **Mega Payouts** — rare 100Mx multipliers in Sky City, 50Mx down below
- **15-Minute Blackouts** — robots hunt you during blackouts. Use escape portals or let Rusty distract them
- **School System** — enroll in high school or college, attend classes to earn time, take futuristic electives (Robotics, Hacking 101, Vehicle Creation, Time Portal Class, and more)
- **Property & Business** — buy properties for passive income, upgrade them, create businesses, launch your own crypto currency
- **Hover Vehicles** — buy and ride hover bikes, boards, cars, and flying vehicles
- **Cloud Nybus** — summon a flying cloud for fast travel
- **Hyperloop** — fast travel between 8 stations across the city
- **Sky City** — the elite city in the sky (requires 10,000 INC or 20 hours to access)
- **Underground City** — explore beneath the Central Brain for advanced tech
- **Keyhouse** — explore the Lock & Key manor, find magical keys, forge new ones
- **Courthouse** — face trials, create businesses, transfer property titles
- **Casino** — slots, dice, blackjack, roulette
- **Hacking** — hack buildings, the Central Brain (needs level 3)
- **NPC Life Simulation** — 80 NPCs walk the city with their own tasks. Walk near them to auto-add contacts
- **Phone System** — contacts, messages, mission notifications
- **Loan System** — take out loans at the bank, pay them back to unlock higher tiers (10 → 20 → 40 → 80)
- **JARVIS Integration** — voice/text AI assistant speaks proactively for all events: phone messages, mission updates, job offers, class reminders, low time warnings, blackout alerts, robot chase alerts, and more
- **Mouse Controls** — hold left click to steer, right click for game menu, command bar at bottom
- **Command Bar** — type natural language commands ("go to bank", "take loan", "talk to rusty", etc.)

## Controls

| Key | Action |
|-----|--------|
| WASD / Arrows | Move |
| Mouse (hold left) | Steer toward cursor |
| E or Left Click | Interact / Enter building / Talk to NPC |
| Right Click | Game menu |
| T | Talk to Rusty (companion) |
| P | Phone |
| F | Fast Travel |
| B | Properties |
| H | Hack nearby |
| V | Mount/dismount vehicle |
| C | Summon Cloud Nybus |
| ESC | Pause |
| Command bar | Type commands at bottom of screen |
